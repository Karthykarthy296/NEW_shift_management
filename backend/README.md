# ShiftAI - Backend Service

This is the backend service for **ShiftAI**, a premium, AI-powered workforce scheduling and shift management system. The service is built with FastAPI, using SQLAlchemy for flexible SQLite/MySQL database support, and integrates an AI scheduling optimizer.

---

## 🚀 Key Features

* **AI-Driven Scheduling Engine**: Multi-constraint heuristic algorithms that automatically assign shifts and balance weekly offs based on employee preferences and department demands.
* **Role-Based Access Control (RBAC)**: Fine-grained security allowing customized permissions for **Admins**, **Managers**, and **Supervisors**.
* **Flexible Database Engine**: Configured to run on **MySQL** as the primary high-performance production database, with **automatic fallback to SQLite** for zero-downtime development safety.
* **Bulk Operations & Excel Integration**: Robust parser for automated onboarding of personnel and scheduling directly from spreadsheets.
* **Safe Migration Pipeline**: Built-in topological database migration script (`migrate_db.py`) to port data from SQLite to MySQL without any record loss.
* **API Documentation**: Interactive OpenAPI swagger docs automatically generated by FastAPI.

---

## 🛠️ Technology Stack

* **Framework**: [FastAPI](https://fastapi.tiangolo.com/) (Python 3.14 compatible)
* **ASGI Server**: [Uvicorn](https://www.uvicorn.org/)
* **ORM**: [SQLAlchemy 2.0](https://www.sqlalchemy.org/)
* **DB Driver**: [PyMySQL](https://pymysql.readthedocs.io/)
* **Security & Auth**: [JWT (JSON Web Tokens)](https://pyjwt.readthedocs.io/) & [Bcrypt](https://passlib.readthedocs.io/)
* **Excel Parsing**: [Pandas](https://pandas.pydata.org/) & [Openpyxl](https://openpyxl.readthedocs.io/)

## ⚙️ Getting Started

### Prerequisites
* **Python 3.10+** (Python 3.14 recommended)
* Optional: **MySQL Server** (if utilizing production mode)

### 1. Installation

1. Navigate to the backend directory:
   ```bash
   cd backend
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### 2. Configuration (`.env`)

Copy the template env file and set your credentials:
```bash
cp .env.example .env
```
*Modify your `.env` to define your environment parameters (e.g. database credentials, JWT secret keys, etc.).*

### 3. Running the Server

Start the development server with hot-reloading active:
```bash
uvicorn main:app --reload
```
The server will boot on [http://localhost:8000](http://localhost:8000).

* **Interactive API Docs**: Go to [http://localhost:8000/docs](http://localhost:8000/docs) (Swagger UI) or [http://localhost:8000/redoc](http://localhost:8000/redoc) (ReDoc).

## 💾 Database Migration (SQLite to MySQL)

If you are running on SQLite and want to safely port all existing records to MySQL:

1. Configure your MySQL credentials in `.env` and set `DATABASE_TYPE=mysql`.
2. Ensure your MySQL server is running.
3. Execute the migration script:
   ```bash
   python migrate_db.py
   ```
This script will safely back up your SQLite database, create target tables in MySQL, transfer records topologically, compare counts, and validate success.
